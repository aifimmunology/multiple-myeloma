# analyses-msd/

MSD (Meso Scale Discovery) cytokine assay cleaning for the NDMM cohort — flu and COVID vaccination response data into analysis-ready tables.

## Scripts

| File | Description |
|---|---|
| `01-flu-data-cleaning.ipynb` | Cleans/standardizes MSD cytokine data from flu-vaccination timepoints |
| `02-covid-vaccine-cleaning.ipynb` | Cleans MSD cytokine data from the COVID-vaccination series |

Scripts are independent; run either as needed.

## Environment

R

## Data

Raw MSD plate files and cleaned outputs under `data/msd/`.
